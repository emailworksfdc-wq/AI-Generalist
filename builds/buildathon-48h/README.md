# Buildathon — Personal 48-Hour Build

**Days 26–27 (2026-08-28 to 2026-08-29)**

## Rules (set by you)

- **48 hours, wall-clock.** Includes sleep. Optimise for the finish line, not for peak hours.
- **Idea locked before Day 26 starts.** Use Day 25 evening to pick.
- **No new tech.** Only stacks you've already touched in the previous 25 days.
- **One deployed URL by end of Day 27 or the sprint is a fail.**

## What to build

The buildathon output *is* Signature Build 5 pushed to shippable — don't split them. Use these 48h to close the gap from "prototype" to "live and paid".

## Hour-by-hour skeleton (adjust to reality)

- **Day 26 morning (4h):** Lock idea. Sketch data model. Scaffold with Bolt/Lovable/Cursor.
- **Day 26 afternoon (4h):** Get the core happy path working end-to-end (auth → main action → result).
- **Day 26 evening (2h):** Deploy to Vercel/Railway. Confirm live URL reachable.
- **Day 27 morning (4h):** Wire payments (Stripe checkout). Test in test mode.
- **Day 27 afternoon (3h):** Polish landing page copy. Add pricing block.
- **Day 27 evening (2h):** Switch to Stripe live mode. Text 5 friends the link.
- **Day 27 late night (1h):** Ship post. Bed.

## Anti-goals

- No feature creep. If it wasn't in the Day 25 sketch, it's Day 30's problem.
- No perfect UI. Ship ugly, iterate later.
- No new APIs. If it needs a service you haven't used, you're doing it wrong.
