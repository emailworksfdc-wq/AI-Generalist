Engineering Accelerator Program — official schedule

Full session-by-session breakdown from Om Asnani's Engineering Accelerator Program schedule (Times in IST / EST). Every topic below has been transcribed verbatim from the program schedule.

Sprint 1

Advanced Prompt Engineering and AI Automations

IST 7pm – 11pm EST 9:30am – 1:30pm
Prompt Engineering + Chat Completion / OpenAI Standard
  1. How do you build something like ChatGPT app?
  2. Learn advanced techniques in Prompt Engineering like XML & JSON prompting
  3. As an Engineer, you will not prompt your models — your users will. How do you manage that?
  4. Learn about the world of AI models — who all has them and how to use them as an Engineer?
IST 7pm – 11pm EST 9:30am – 1:30pm
n8n
  1. Learn the fundamentals of workflow automation using n8n, including how triggers, nodes, and data flow work together to build powerful automations.
  2. Understand how to identify repetitive or manual tasks that can be automated in both personal and professional workflows using n8n.
  3. Get hands-on experience building workflows in n8n's visual canvas — starting from basic triggers to multi-step automations that integrate multiple apps.
  4. Explore essential n8n features such as HTTP requests, data transformation, authentication, and scheduling to create end-to-end automation pipelines.
  5. Master automation best practices in n8n, including workflow organization, versioning, error handling, debugging, and optimizing nodes for reliable production-ready workflows.
IST 7pm – 11pm EST 9:30am – 1:30pm
Build app: n8n + Google AI Studio
  1. A full-stack application with n8n as the backend workflow automation platform and AI Studio as the frontend interface.
  2. Custom workflow automations that connect multiple APIs and services — streamlining repetitive personal or professional tasks.
Sprint 2

Full Stack Open Source AI Applications

IST 7pm – 11pm EST 9:30am – 1:30pm
Building AI Applications with Hugging Face, Gradio & Local Models
  1. Learn how to access and run open-source AI models using Hugging Face, local models, and inference APIs.
  2. Build a ChatGPT-like AI application from scratch using Gradio with real-time conversations and multimodal capabilities.
  3. Understand how to integrate AI models, manage user inputs, context, and responses, and choose between local and API-based deployments.
  4. Explore practical AI application development across NLP, vision, and multimodal use cases while strengthening end-to-end AI app-building fundamentals.
Sprint 3

Customising AI & RAG's along Debugging

IST 10am – 2pm EST 12:30am – 4:30am
RAG Basics + LanceDB + LlamaIndex
  1. What is Retrieval-Augmented Generation (RAG) and why is it needed?
  2. Learn how to chunk, embed, and store data using vector databases like LanceDB.
  3. Understand how LlamaIndex helps in building retrieval pipelines.
  4. Build the foundation for querying your own data using LLMs.
IST 10am – 2pm EST 12:30am – 4:30am
Building Atlas
  1. What is Atlas and how does it act as a structured knowledge base?
  2. Learn how to organize, index, and manage large datasets for retrieval.
  3. Design scalable data pipelines for storing and querying information.
  4. Prepare your system for efficient and accurate RAG-based applications.
IST 3pm – 7pm EST 5:30am – 9:30am
Debugging with AI
  1. Learn AI-assisted debugging workflows to identify and resolve errors faster across your applications.
  2. Understand and interpret error messages, stack traces, and logs using LLMs effectively.
  3. Debug every stage of a RAG pipeline — from document loading and chunking to embeddings, retrieval, and response generation.
IST 10am – 3pm EST 12:30am – 5:30am
Build RAG app
  1. How do you build a complete RAG-based application end-to-end?
  2. Integrate retrieval pipelines with LLMs to answer user queries.
  3. Handle context injection, ranking, and response generation.
  4. Deploy a working app that can query and reason over your own data.
Sprint 4

AI Coding Agents — Code generation & Evaluation

IST 7pm – 11pm EST 9:30am – 1:30pm
Codex + Evals
  1. Understand how automation workflows can be built using Codex for engineering and product use cases without relying on connectors or external integrations.
  2. Learn where evaluations (evals) fit into product development and how to think about model-level and application-level evaluation strategies.
  3. Explore how Codex can support security reviews, code understanding, and engineering quality checks.
  4. Get exposure to browser-based automation workflows and practical AI-assisted development patterns.
IST 7pm – 11pm EST 9:30am – 1:30pm
Claude Code + MCP
  1. Learn how coding agents can interact with tools, systems, and workflows using MCP-based integrations.
  2. Understand how to structure engineering workflows with reusable capabilities and external system access.
  3. Explore practical coding and automation workflows using AI agents for development tasks.
  4. Gain exposure to orchestration concepts and how multiple AI-driven workflows can collaborate in engineering systems.
Sprint 5

AI Agents — Observability & Agent Building

IST 7pm – 11pm EST 9:30am – 1:30pm
LangChain + LangSmith
  1. What is LangChain and how does it help in building AI applications?
  2. Learn core components like chains, prompts, memory, and agents.
  3. Understand how to structure and orchestrate multi-step AI workflows.
  4. Use LangSmith for debugging, tracing, and monitoring LLM applications.
IST 7pm – 11pm EST 9:30am – 1:30pm
LangGraph
  1. What is LangGraph and how does it enable agentic workflows?
  2. Learn how to build stateful, multi-step AI systems using graph-based logic.
  3. Handle complex flows with branching, loops, and memory.
  4. Design and orchestrate multi-agent systems for real-world use cases.
IST 7pm – 11pm EST 9:30am – 1:30pm
Cost Optimization
  1. How does pricing work across different AI models (tokens, modalities, context windows)?
  2. Learn practical strategies like caching, batching, and prompt optimization to reduce costs.
  3. Understand how to choose the right model based on use case and budget.
  4. Optimize AI systems for performance vs cost trade-offs in real-world applications.
Sprint 6

Building AI Coding Agent

IST 10am – 2pm EST 12:30am – 4:30am
Building Orion
  1. Build your own AI Engineering Agent.
  2. Learn to create a Discord Bot that can make changes to your projects and raise PRs.
  3. Utilize OpenAI Codex — Cloud and Software Engineering Agents in Parallel.
  4. Combine LangChain, LangSmith, LangGraph and OpenAI Codex.
